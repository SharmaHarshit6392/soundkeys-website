06 / GOOD TO KNOW

Before you press play.

What is SoundKeys?

SoundKeys is a Windows desktop application that plays sounds in response to keyboard input, with Chaos, Custom and Mechanical modes.

Can I use my own sounds?

Custom Mode lets you import sounds and assign them to keys.

Is SoundKeys available to download now?

The website is being prepared. The public installer download will become available once the release is ready.

Where can I see the source code?

The current development source is available on the SoundKeys GitHub branch.
